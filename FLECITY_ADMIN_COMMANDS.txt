Flecity 管理・開発コマンド早見表
================================
更新日: 2026-10-27

[FLEPURI / フレプリ台]

管理コマンドは weazel job のみ利用可能

フレプリ台を設置
/puribooth place

設置プレビュー中
矢印キー        : 前後左右へ移動
Q / E           : 回転
PageUp/PageDown : 高さ調整
Shift           : 高速調整
C               : 撮影カメラ確認
Enter           : 設置確定
Backspace       : 設置キャンセル

近くのフレプリ台を撤去
/puribooth remove
※未回収売上が残っている台は撤去不可

近くの台の料金変更
/puribooth price 1500

台IDを指定して料金変更
/puribooth price 1500 3

全台の料金・未回収売上・累計売上・撮影回数を確認
/puribooth sales

全台の未回収売上を会社口座へ回収
/puribooth collect all

指定台だけ回収
/puribooth collect 3

設置済み台数を確認
/puribooth list

[利用者の撮影操作]

背景・床選択画面
「撮影をやめる」 : 撮影開始前キャンセル（返金）

背景選択後
E               : カメラ確認へ
R               : 背景・床を選び直す（追加料金なし）
G               : 撮影範囲ガイド 表示/非表示
Backspace       : 撮影中止（撮影開始前なら返金）

撮影範囲ガイド
白枠            : 実際に写る横幅の目安
緑枠            : 人物が切れにくい安全範囲
白い丸          : 最大4人用の立ち位置目安

カメラ確認
E               : 撮影開始
R               : 背景・床を選び直す（追加料金なし）
G               : 撮影範囲ガイド 表示/非表示
Backspace       : 一つ前へ戻る

2〜4枚目の POSE READY
E               : 次のカウントダウン開始
Backspace       : 残りの撮影を中止（撮影開始後なので返金なし）

[PuriBooth 編集画面]
スタンプ/文字をクリック : 選択
ドラッグ                : 選択したスタンプ/文字を移動
Ctrl+Z                  : 装飾を戻す
Ctrl+Y / Ctrl+Shift+Z   : やり直す
Delete                  : 選択した装飾を削除
Esc                     : 選択解除

[txAdmin / サーバーコンソール]

PuriBoothだけ再起動
restart puribooth

PuriPhotoだけ再起動
restart puriphoto

リソース再読込
refresh

PuriBooth自己診断
puribooth_selftest

[開発ビルド反映]

PowerShell:
git -C D:\FiveM_Dev\_puriphoto_booth fetch origin puriphoto/booth-dev
git -C D:\FiveM_Dev\_puriphoto_booth reset --hard origin/puriphoto/booth-dev
powershell.exe -NoProfile -ExecutionPolicy Bypass -File D:\FiveM_Dev\_puriphoto_booth\puribooth-update.ps1

PuriBoothだけの変更だと分かっている時だけ:
powershell.exe -NoProfile -ExecutionPolicy Bypass -File D:\FiveM_Dev\_puriphoto_booth\puribooth-update.ps1 -BoothOnly

その後 txAdmin:
restart puriphoto
restart puribooth

[注意]
・通常はサーバー全体を再起動しない。
・PuriBooth変更は原則 restart puribooth だけで反映する。
・PuriPhoto側を変更した時だけ restart puriphoto も実行する。
・[qbx] や [lb-phone] をPowerShellから扱う場合は -LiteralPath を使う。
