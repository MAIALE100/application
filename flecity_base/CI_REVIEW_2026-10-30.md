## Transaction / security review

Compared the upstream oxmysql `lib/MySQL.lua`,
`src/database/startTransaction.ts`, and `src/database/connection.ts`.
The helper forwards startTransaction; query returns raw row arrays for SELECT
and ResultSetHeader tables for writes (insertId/affectedRows), and the transaction
returns a boolean. Existing strict committed=true checks agree with this contract.
This does not establish the version installed on the test server.

Stock definitions/create/configure require server-side manager authority;
adjustments/list require membership. Types are read from workspace-scoped DB
definitions. Value reads join both item and field workspace ownership; regular
members get visible definitions/values only. Managers can recover hidden values.
Stock create/history and configure/values share transactions. Invite and stock
creation serialize on workspace rows; stock adjustments lock the item.
Real SQL rollback, isolation behavior and concurrent permission changes remain
integration-test gates, not proven by mocks or source inspection.
