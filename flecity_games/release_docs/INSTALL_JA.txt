Flecity Games LOOP v1.0.0
運営様向け 導入方法

この度は導入のご確認をいただき、ありがとうございます。
お手数をできる限り増やさないよう、通常はリソース配置と ensure のみで導入できる構成にしております。

■ 今回の提出内容
・LB Phone用カスタムアプリ「LOOP」
・一人用ミニゲーム 15種
・ランキング / Daily Challenge / 実績 / 途中保存
・LOOPはLB PhoneのApp Storeから各プレイヤーが無料でダウンロードする方式です。\n・今回の提出版では PARTY アプリは非表示にしています。

■ 前提
以下のリソースが稼働している環境を前提としています。
・qbx_core（Qbox）
・oxmysql
・lb-phone

LB Phone本体、Qbox本体、その他既存リソースのファイルを書き換える必要はありません。

■ 導入手順
1. ZIP内の「flecity_games」フォルダをサーバーの resources 配下へ配置してください。

2. server.cfg で qbx_core / oxmysql / lb-phone より後に、以下を1行追加してください。

ensure flecity_games

3. サーバー稼働中に導入される場合は、サーバーコンソールで以下をご実行ください。

ensure flecity_games

既に起動済みの同名リソースを更新される場合のみ、

refresh
restart flecity_games

で反映できます。通常、サーバー全体の再起動は不要です。

■ データベース
起動時に必要なテーブルを自動作成・不足項目を補完するため、通常はSQLの手動実行は不要です。

作成されるテーブル：
・flecity_game_profiles
・flecity_game_scores
・flecity_game_saves
・flecity_game_achievements
・flecity_game_daily

DROP TABLE / TRUNCATE TABLE は実行しません。
万一、DBユーザーにCREATE / ALTER権限が無い場合のみ、同梱の sql/001_initial.sql をご確認ください。

■ 起動確認
正常時はサーバーコンソールに概ね以下が表示されます。

[FlecityGames] database schema ready
[FlecityGames] LB Phone callbacks registered .../...
[FlecityGames] startup preflight READY_FOR_LIVE_TEST

ゲーム内LB Phoneに「LOOP」が表示され、起動できれば基本導入は完了です。

■ 確認用コマンド
必要な場合のみ、サーバーコンソールから以下をご利用いただけます。

game_status
game_preflight
game_selftest
game_healthcheck

いずれも確認用で、プレイヤーデータを削除するコマンドではありません。

■ 取り外し / ロールバック
問題がございましたら、

stop flecity_games

で停止できます。
server.cfg の ensure flecity_games を外していただければ、次回起動時にも読み込まれません。

作成済みの Flecity Games 用DBテーブルは残っていても、リソース停止中は他アプリへ影響しません。

導入にあたり、LB Phone本体や既存アプリの変更作業をお願いする構成にはしておりません。
ご確認のほど、よろしくお願いいたします。
