Flecity Games PARTY v1.0.0
運営様向け 確認用メモ

■ 変更範囲
・更新リソース：flecity_games
・LB Phone：AddCustomAppによるPARTY追加
・Qbox core：変更なし
・LB Phone core：変更なし
・oxmysql：既存APIを利用
・LOOPのidentifier / score / save / achievement仕様：変更なし

■ PARTY
・identifier: flecity_party
・表示名: PARTY
・defaultApp=false
・game=true
・price=0
・2〜10人（ゲームごとに対応人数を制限）
・4桁ルームコード
・Ready制
・ホストのみゲーム選択 / 開始 / 結果後ロビー復帰
・二重開始 / 二重submit / 古いround submitをserver側で拒否
・切断時cleanup、ホスト移行、60秒再接続猶予
・ラウンド / 手番timeout
・WORD WOLF / LIAR / DRAW / TELEPHONEの秘密情報はviewer別snapshot
・DRAW描画量上限
・TELEPHONE途中離脱時は手番skip

■ LOOP
・表示名: LOOP
・identifier: flecity_play
・defaultApp=false
・game=true
・price=0
・既存のスコア / 実績 / セーブ / Daily / ranking仕様を維持
