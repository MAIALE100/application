Flecity Games LINK v1.0.0
運営様向け 確認用メモ

■ 更新概要
・更新resource：flecity_games
・既存LOOPを維持したままLINKを追加
・resource提出版version：1.1.0
・LB Phone core：変更なし
・Qbox core：変更なし
・server.cfg：既存「ensure flecity_games」を継続使用
・サーバー全体再起動：通常不要

■ 本番前提
・QBox 2.5.4
・oxmysql
・citizenid = CSN
・LB Phone 2.9系

■ LOOP維持事項
・identifier: flecity_play
・name: LOOP
・defaultApp=false
・game=true
・price=0
・score / BEST / save / achievement / Daily / ranking互換を維持
・既存DBデータを削除しない

■ LINK
・identifier: flecity_party
・name: LINK
・defaultApp=false
・game=true
・price=0
・2〜10人（ゲーム別人数制限あり）
・4桁Room code
・Ready制
・Hostのみゲーム選択 / 開始
・切断cleanup / Host移行 / 60秒再接続猶予
・二重Start / 二重submit / 古いround submitをserver側で拒否
・round / turn timeout
・秘密情報はviewer別snapshot
・App / Phone close時の進行停止対策
・7〜10人Room向け小画面UI対策

■ ゲーム構成
全15種を登録し、毎週ワードウルフ以外から5種をLINK+対象として切り替えます。今週の対象と切替予定をアプリ内表示で確認してください。

■ LINK+
・7日 / 50,000
・加入HostのRoomでは未加入参加者もLINK+ゲームを利用可能
・購入はserver側で処理
・プレイヤーbankから50,000を減算
・自動更新停止可
・停止後も期限までは利用可能
・期限後の次回LINK利用時に1期間だけ自動更新を試行
・残高不足時は更新失敗として処理

■ LINK+売上
売上先：WEAZEL企業口座
account name：weazel
provider：auto

provider autoの判定順：
1. Renewed-Banking
2. qb-banking

企業口座への入金に失敗した場合：
・購読を成立させない
・プレイヤーへ50,000返金を試行

企業口座入金後に購読DB保存が失敗した場合：
・WEAZEL口座から入金額を取り消す
・プレイヤーへ返金を試行
・rollback不完全時はserver consoleへCRITICALログを出力

■ データベース
・LINK Roomはメモリ管理
・永続Roomテーブルは追加しない
・LINK+のみflecity_game_subscriptionsへ保存
・citizenid(CSN) / active_until / auto_renewを保持
・通常はSQL手動実行不要
・DROP TABLE / TRUNCATE TABLEなし
