# Flecity JAM — 0.3.1-test 開発候補

街で楽器を演奏し、近くの人と音を共有する独立したFiveMリソースです。**現在はテスト版です。住民向け正式公開の判定はまだ行っていません。**

ピアノ、アコースティックギター、エレキベース、クラリネット、ドラムの5楽器を収録しています。PCキーボードや画面の鍵盤で演奏でき、和音・長押し・サステイン・オクターブ変更に対応します。対応環境ではMIDI入力も選べます。近くの演奏を聴く音量と、自分の演奏音量を別々に調整できます。

使い始めるには `/jam` → 楽器を選択 →「演奏する」。終了はEscまたは`/jamstop`です。聴くための設定だけを開く場合は`/jamlisten`、消音の切替は`/jammute`です。

## 0.3.1-testの白鍵・黒鍵配列

- 標準は2オクターブの25音です。白鍵は下段 `Z X C V B`、高音側は `Q W E R T Y U I O P`。黒鍵は各列の上の `S D G H` と `2 4 5 7 8 9` に分けます。ピアノ初期はC3～C5で、画面鍵盤にも同じキーを表示します。
- Nを通常PTT用の予約キーとして空けるため、下段はGで終え、QからAへ続きます。JISで印字が変わる記号キーを標準では使いません。**オクターブ変更は全配列で↑／↓または画面ボタン。Z／Xは音符専用**です。
- 従来18音と3段36音は別プリセットとして残します。変更済みの個人配列は選択状態を維持し、旧標準36音の利用者には新25音を初期表示します。旧保存データを削除・上書きせず、端末設定v3へコピーします。
- 画面の横スクロール・拡大縮小はPCキーの音高と独立しています。和音・長押し・サステイン・キー変更・対応環境でのMIDIを維持し、同時発音上限は16音です。楽器の音域外は無効表示になります。
- 入力をJAMへ専有させる対策を維持します。U/Jなどの誤発動とPTTの実動作は未確認です。会話・無線時はEscまたは`/jamstop`で閉じ、`/jam`で戻ります。Voice設定は変更しません。

[MIMIの公式プロジェクト](https://github.com/tofodroid/mimi-mod)を参考に、白鍵と黒鍵の段を分ける考え方を採用しました。MIMIの配列をそのまま移植せず、Nの予約とJISへの対応を優先したJAM独自の25音配置です。詳細は[操作マニュアル](docs/MANUAL_JA.md)を参照してください。

この版の**FiveMでの実打鍵、5楽器の音、2人での距離・バケット・途中参加、PTT、物理MIDIはNOT_RUN**です。ユーザーが出張先ノートPCで実機確認を行い、デスクトップではFiveMを起動・操作しません。自動試験の件数と設置状況は実行後の別添QAを参照してください。住民向け正式公開はNO-GOです。

## 0.2.2-testの変更点

- 通信内で短い打鍵の開始と終了がまとまっても、ピアノ・ギター・ベース・クラリネットの発音が無音にならないよう修正しました。
- 音声を準備している間に画面を閉じたり開始操作を取り消した場合、メトロノームが裏で動き始めないようにしました。
- 配布・更新手順を整理しました。詳細な検証範囲と実機の未確認項目は別添QAを参照してください。

## 0.2.1-testの変更点

- 周囲の演奏者の位置や音源の読み込みが遅れたとき、短い音符を最大250msだけ保持して再生します。距離外、演奏終了、セッション変更時には破棄します。
- `/jamlisten` で音声が停止している場合、画面の「JAMの音声を有効にする」から再試行できます。
- 演奏者の初回位置情報を音符と同じ受信処理で渡し、近距離の最初の短音を取りこぼしにくくしました。
- 実FiveM聴感、複数人合奏、PTTは、各版の実機証拠で別途判定します。

## 0.2.0-testの変更点

- 起動時の通信・音源準備が失敗した際に、画面から再読み込みできるようにしました。演奏開始時には音声の再開を再確認し、失敗の段階に応じて再試行方法を表示します。
- 聴く音量と消音状態を端末に保持します。音が聞こえないときは、まず「消音中」と「聴く音量」を確認してください。
- エレキベースの初期オクターブを1にし、最初に押せるE1を鍵盤上のDキーへ配置しました。
- ピアノの弱いベロシティ層（v2）の音量メタデータを測定値で補正しました。録音サンプル自体は変更していません。
- 発音数の管理で、鳴っている音と余韻中に確保された音声ノードを区別し、連打時のノード上限を守るようにしました。

FiveMとOneSyncが必要です。JAMはWAVE、LB Phone、QBox、oxmysql、pma-voiceを直接の実行依存にせず、DBも使用しません。既存のVoice設定には変更を加えません。

過去の0.1.0-testでは、FiveMでメトロノームとピアノC4をユーザーが聴取しました。初回発音、5楽器の聴感、複数人の合奏、PTTとの共存は、**このREADMEだけで合格とは判定しません。** 版ごとの自動試験と実機結果、未確認事項は、別添の最新QA記録を確認してください。
