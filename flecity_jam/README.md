# Flecity JAM — 0.5.0-test テスト版

## 動かせる楽器画面・ボタン不要の演奏

「移動」をドラッグしてパネルを配置し、設定から小さめ／標準／大きめを選べます。画面サイズへ収め、詳細表示や縮小でも会話状態と閉じる操作を残します。移動ハンドルは矢印10px、Shift＋矢印40px、Homeまたは「中央へ」で位置と大きさを戻せます。このPCだけの画面設定です。

演奏ボタンは廃止。PCキー・画面鍵盤・MIDIの入力から準備と権限確認を始めます。初回の短い入力は限定した準備待ち内だけ1回反映し、長い読み込み後に古い入力をまとめて鳴らしません。

認証された演奏中は通常会話の入力を自動ONにし、Nを押し続ける必要をなくします。上部でOFFにでき、終了・画面切替・通信断・期限切れでは解除します。マイク無効・ミュート・Voice・無線設定は変更しません。会話距離は既存Voiceのままです。実際に相手へ聞こえるかはノートPC確認待ちです。

[GarageBand iPhoneのApple公式ガイド](https://support.apple.com/ja-jp/guide/garageband-iphone/chs39282dbe/2.3.18/ios/26)を参考に、鍵盤を主役に音域・サステイン・音量を近くへまとめました。録音機能や素材の複製は行っていません。最新QAは別添floating-ui-20261118を正本とします。実FiveM・音声・PTT・CEFはNOT_RUN、正式公開はNO-GOです。以下は旧版の履歴です。

## 継続する会話入力・15m共有

0.3.1-testでは、ユーザーのノートPCで操作・楽器発音・周囲への共有・距離減衰・2人以上の合奏がPASSしました。一方、JAMを開いた本人のVCはFAILで、Escで閉じるとすぐ復帰しました。原因は未確定です。

この候補では、JAM表示中に**Nまたは「会話・押している間」ボタン**から通常PTTの入力を渡します。ゲーム操作へ入力を広く通す設定には戻さず、249の通常PTTだけを対象にします。入力待機・PTT入力中・送信状態の検出を区別し、**「送信状態を検出」は相手に聞こえた証拠ではありません**。Nを離す、画面を閉じる、フォーカスが外れる、通信が途切れる等で入力を解除します。マイクOFFやVoiceのミュート、無効なコントロールを勝手に解除しません。声が届かない場合や無線の使用時はEscで閉じてください。

JAMの共有距離はユーザー指定の**15m**へ変更します。既存の二乗減衰を維持し、15m以上は無音です。Voiceの通話距離や設定とは独立しています。15mでの実際の聞こえ方と、候補の会話入力は未検証です。

## 維持する白鍵・黒鍵配列

- 標準は2オクターブの25音です。白鍵は下段 `Z X C V B`、高音側は `Q W E R T Y U I O P`。黒鍵は各列の上の `S D G H` と `2 4 5 7 8 9` に分けます。ピアノ初期はC3～C5で、画面鍵盤にも同じキーを表示します。
- Nを通常PTT用の予約キーとして空けるため、下段はGで終え、QからAへ続きます。JISで印字が変わる記号キーを標準では使いません。**オクターブ変更は全配列で↑／↓または画面ボタン。Z／Xは音符専用**です。
- 従来18音と3段36音は別プリセットとして残します。変更済みの個人配列は選択状態を維持し、旧標準36音の利用者には新25音を初期表示します。旧保存データを削除・上書きせず、端末設定v3へコピーします。
- 画面の横スクロール・拡大縮小はPCキーの音高と独立しています。和音・長押し・サステイン・キー変更・対応環境でのMIDIを維持し、同時発音上限は16音です。楽器の音域外は無効表示になります。
- 入力をJAMへ専有させる対策を維持します。Nは音符に割り当てず会話入力用とし、CapsLock等の予約も維持します。U/J等の競合とPTTの実動作は候補ごとに確認し、Voice設定を変更しません。

[MIMIの公式プロジェクト](https://github.com/tofodroid/mimi-mod)を参考に、白鍵と黒鍵の段を分ける考え方を採用しました。MIMIの配列をそのまま移植せず、Nの予約とJISへの対応を優先したJAM独自の25音配置です。詳細は[操作マニュアル](docs/MANUAL_JA.md)を参照してください。

この0.4.2候補の**FiveMでの打鍵・新3楽器の音・個別聴取音量・15m共有・合奏・VC送受信・物理MIDIはNOT_RUN**です。旧版の報告を候補のPASSへ繰り越しません。ユーザーがノートPCで実機確認を行い、デスクトップではFiveMを起動・操作しません。自動試験の件数と設置状況は実行後の別添QAを参照してください。住民向け正式公開はNO-GOです。
