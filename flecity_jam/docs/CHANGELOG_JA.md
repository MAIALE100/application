# 変更履歴

## 0.3.0-test — 開発候補・2026-11-17

PCキーボードでの演奏を、3段×12半音の36音へ広げる作業です。ピアノの標準配置は下段C3～B3、中段C4～B4、上段C5～B5。鍵盤画面の横スクロール・拡大率は表示だけを変え、キー割り当ては変えません。従来18音と保存済みの個人設定は維持します。同時発音上限は16音、ドラムは8パッド、5楽器と58音源は従来どおりです。

演奏画面の入力はNUIへ向け、ゲーム側の操作を抑制します。PTTの実機動作は未確認のため、会話時にはEscまたは`/jamstop`で画面を閉じて戻る方法を案内します。Voice設定は変更しません。

この項目は実装中の仕様説明であり、**0.3.0-testの回帰件数、テストサーバー反映、FiveMでの打鍵・5楽器聴感・2人合奏・PTTをPASSとするものではありません**。完成した候補と実際の検証結果は別添の最新QAで確認してください。

## 0.2.2-test — 2026-11-17

短い打鍵のNote On/Offが同じ通信パケットに入ると、発音直後の音量0でアタックが取り消されていた問題を修正しました。最短20msの発音とアタックを確保してから余韻へ移行します。ピアノ、ギター、ベース、クラリネットの実PCMをレンダリングし、修正前の無音と修正後の発音・停止を比較しました。

音声再開を待っている間に画面を閉じた場合や開始操作を取り消した場合、メトロノームの古い非同期処理を無効にします。共通検証から漏れていた音源読み込み遅延テストも実行対象へ追加しました。

ネイティブLua 5.4.8でサーバー状態機械21件、FiveM APIを模擬するクライアント11件がPASS。FiveM実機・複数人・聴感・PTTの判定とは区別します。

## 0.2.1-test — 2026-11-16

初回の周囲聴取で位置情報が遅れる場合、短い音が失われる経路を修正しました。音源の読み込み中や位置の取得待ちで終了した音符は、最大250ms・演奏者ごとに16音まで保持し、近距離で準備が整った場合だけ再生します。遠距離、演奏終了、セッション変更、期限切れでは破棄します。

聴取専用画面に音声を有効化する操作を追加し、音声コンテキストが停止している場合の再試行と失敗表示を用意しました。実時間の音声コンテキストが停止中は遠隔音を予約せず、オフライン音声描画の試験は維持します。

この版はローカル回帰を通過した開発候補です。FiveM実機の発音、複数人合奏、PTT、音質は改めて確認が必要です。テストサーバー設置版は引き続き0.2.0-testです。

## 0.2.0-test — 2026-11-16

音声開始・音源読み込みに待機上限と再試行を追加。起動失敗時は画面内から再読み込みできます。セッションごとに送信待ちを分離し、古い通信結果が次の演奏を停止しないようにしました。JAMが開いていない時に他のNUIの入力を解放する処理を修正しました。

余韻中の音も128音源ノードの上限に含め、連打時の無制限な増加を防止。消音設定の初回適用、閉じたAudioContextの復旧、MIDIの不正パケット・複数チャンネルのペダル・抜き差しを改善しました。ピアノの強弱レイヤー間の音量差を測定値に基づいて補正し、ベースの初期表示を低音域へ移しました。58音源ファイルは変更していません。

配布ZIPから開発資料を除外し、設定不一致で停止する更新・全体バックアップ・固定ハッシュによるロールバックを用意しました。ローカル模擬試験と実FiveMの結果は別のQA記録を参照してください。複数人合奏・PTT・実機MIDI・聴感評価の未確認項目がある間は、正式なリリース候補完成とは判定しません。
