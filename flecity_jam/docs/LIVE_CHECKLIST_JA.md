# 0.3.2-test 実FiveM受入試験 — 現在 NOT_RUN

実機操作はユーザーの出張先ノートPCで行い、デスクトップFiveMは起動しません。共有・通話の確認には2人のクライアントが必要です。0.3.1のユーザー報告は操作・楽器発音・周囲共有・減衰・2人以上合奏PASS、本人VCはFAILでEsc後すぐ復帰でした。これは0.3.2の結果ではありません。以下はすべてNOT_RUNで、ブラウザーのPASSでは代替できません。識別子・認証情報・会話音声を資料へ含めず、対象版と日時を記録します。

| 区分 | 手順 | 合格条件 |
|---|---|---|
| 初回・復旧 | 初回接続、/jam、演奏する、再表示、再接続、JAM単体再起動 | 初回から発音。失敗時は「JAMを再読み込み」または段階別の再試行案内で復旧し、黒い覆いやフォーカス残留がない |
| 消音設定 | 消音、聴く音量、閉じて再表示、/jammute | 設定が保持され、解除後に音が戻る。無音の原因が画面から分かる |
| 各楽器 | ピアノ、ギター、ベース、クラリネット、ドラムを順に演奏 | 5楽器とも聞こえ、画面の有効音域内で弾ける。音域外は無効 |
| 入力 | 白鍵・黒鍵25音、三和音、連打、長押し、Space、↑↓、Z/X | 音抜け・残留・別操作なし。Z/Xは音符になり、音域変更を起こさない |
| 配列・表示 | Z/X/CとQ/E/U/P、黒鍵S/D/2/4/7を演奏し画面と比較。スクロール・倍率・音域変更 | 白鍵・黒鍵とラベルが一致。表示だけの操作でPCの音高が変わらない |
| 設定移行 | 旧カスタム18/36音、初回v3移行、再表示、プリセット切替 | 個人設定と選択が残り、v1/v2が不変。新標準25音から旧配列へも戻れる |
| 音質 | 低音〜高音、弱／強、長音10秒、和音 | ノイズ、音割れ、大きい音量差、ループの揺れがない |
| 共有 | A演奏、Bを1m／3m／7m／10m／15m／20mへ移動 | 15m未満で減衰、15m以上で無音。本人の二重再生なし。数値倍率を聴感の割合と扱わない |
| 途中参加 | Aが長音、Bが範囲外から近づく | 頭から弾き直さず、現在の持続位置から聞こえる |
| 合奏 | ピアノ＋ギター、ベース＋ドラム、同一楽器2人 | 他人のノート／ペダルを止めない、実用的なタイミング |
| 移動 | 演奏者を外部移動・テレポート、聴取者移動 | 位置追従、旧位置の音残りなし |
| Bucket | Bだけ別Bucket、続いてAも移動 | 別Bucketへ新規音が届かず、既存音も停止 |
| 死亡・切断 | 演奏中の死亡、切断、再接続 | 音とUI・Propの片付け、正常に再演奏 |
| resource | 演奏中にJAMだけstop/ensure | 音声・フォーカス・Propの残留なし |
| UI | インベントリ、LB Phone、チャット、Pause、Alt-Tab | 競合時に消音・終了でき、操作不能にならない |
| 通常VC | JAMを開きNを保持、次に会話ボタンを保持し、相手側の聴取を確認 | 相手に届いて初めてPASS。PTT入力中／送信状態検出だけでPASSにしない |
| VCの解放 | N／ボタン解放、Alt-Tab、Esc、再表示。許可された隔離条件で死亡・JAM停止等も確認 | 意図しない送信・音・フォーカス残留なし。通信断時の期限解除も別判定 |
| VCの安全性 | 既存のマイクOFF・Voiceミュート等を維持した状態を確認。無線時はEscで閉じる | JAMが既存の停止設定を解除しない。無線を勝手に操作しない。制約のため未実施ならNOT_RUN |
| 既存操作 | U/J等のゲーム操作、通常操作へ戻った後のPTT・無線・距離切替 | JAM中の誤発火と終了後の復帰を別判定。問題時はEscで閉じる |
| MIDI | 実機接続、ペダル、ベロシティ、抜き差し | 使用許可を出せる、解除時に音が残らない |
| 権限 | 無権限、アイテムなし、演奏中に譲渡 | 開始拒否・既存演奏停止 |
| Prop | Presentation=trueでギター | 自他の見た目・キャンセル・復旧を確認。未合格ならfalseを維持 |
| 遅延 | 実接続の遅延・揺れ、複数人連打 | 合奏評価を記録。ローカルテスト値と混同しない |
| 継続 | 8人で最低30分、可能なら2時間 | resmon、FPS、音声キャッシュ、イベント量、終了後の残留を確認。`voices`（発音中）と`nodes`（余韻中を含む）を区別し、余韻終了後にノードが減ることを確認 |

操作不能時は `/jamstop`、音だけ止める場合は `/jammute`。管理者は `stop flecity_jam` で対象だけを停止できます。失敗した項目はFAIL、未実施はNOT_RUN、実行できないものはBLOCKEDと記録します。

本番前に、正式環境のQBox/Voice/Inventoryの版、通常VC距離、アイテム名、ACE、Prop、同時演奏上限、CPU負荷と配布ライセンスの同梱を確認してください。実機の音声共有・合奏が未合格のまま完成80〜90%とは判定しません。
