# 演奏のしかた

`/jam`で開き、楽器を選んで「演奏する」を押します。音源の準備が終わると演奏できます。PCキーボードのIMEはオフにしてください。鍵盤をマウスで押すこともできます。

JAMを開いた時点で準備エラーが出たら「JAMを再読み込み」を押してください。改善しない場合はEscで閉じて開き直します。演奏開始時に音源や通信のエラーが出た場合は、画面の案内に従って少し待ってから「演奏する」を押し直してください。連打しても準備中の操作は重ねて実行されません。

| 操作 | キー・ボタン |
|---|---|
| 音符の演奏 | 画面に表示されたPCキーを押す。標準は白鍵・黒鍵を分けた25音（ピアノ初期C3～C5） |
| 画面の鍵盤を見る | 鍵盤部分を左右にスクロール。拡大率でキーの幅を調整。PCキーの割り当ては変わらない |
| 旧配列を使う | キー設定で「従来18音」または「3段36音」を選ぶ。以前の個人用割り当ても保持 |
| オクターブ | ↓で下げる、↑で上げる。または画面ボタン。全配列共通で、Z/Xとは重複しない |
| サステイン | Spaceを押している間ON。画面ボタンは固定ON/OFF |
| 演奏終了 | Esc、終了ボタン、または`/jamstop` |
| 音だけ止める | 「すべての音を止める」 |
| 演奏音量 | 自分の楽器の音量。周囲にも反映 |
| 聴く音量 | 自分が聴くJAM全体の音量。他人には影響しない |
| 消音 | 消音ボタン、または`/jammute`。VCには影響しない |
| 設定画面だけ開く | `/jamlisten` |
| 画面を小さくする | 縮小。PCキーの演奏は継続 |

## 標準25音の配置

白鍵を横一列、黒鍵をその上の列に分けています。ピアノ初期との対応は次のとおりです。↑／↓で音域を変えても、白鍵・黒鍵の並びは維持します。

| 物理キー列 | PCキー | ピアノ初期の音 |
|---|---|---|
| 下の白鍵列 | Z X C V B | C3 D3 E3 F3 G3 |
| その上の黒鍵列 | S D G H | C♯3 D♯3 F♯3 G♯3 |
| 高音側の白鍵列 | Q W E R T Y U I O P | A3 B3 C4 D4 E4 F4 G4 A4 B4 C5 |
| その上の黒鍵列 | 2 4 5 7 8 9 | A♯3 C♯4 D♯4 F♯4 G♯4 A♯4 |

Nは通常PTT用に予約するため、下段の白鍵をGまでにし、QからAへ続けます。文字と数字だけを使うので、JIS/USで記号キーの印字が違っても標準配列を共通に使えます。実際のノート名とPCキーは画面鍵盤にも表示します。IMEはオフにしてください。

[MIMIの公式プロジェクト](https://github.com/tofodroid/mimi-mod)の演奏体験を参考にしたJAM独自の配列です。標準25音、従来18音、3段36音は別プリセットで、キー設定で変更対象の音を押してから新しいキーを押せます。重複、Esc、Space、方向キー、通常PTT用N、CapsLock、システムキーなどは割り当てられません。**オクターブ変更は全配列で↑／↓に統一し、Z/Xでは変更しません。**

旧版で変更済みの個人配列は選択を維持します。以前の標準36音は新標準25音で始まりますが、3段36音を選べば従来どおり弾けます。端末設定v1/v2は読み取りだけにし、別のv3へコピーして保存します。元の保存データは削除・上書きしません。

画面の鍵盤はPC配列より広い音域を表示し、横スクロール・拡大縮小・表示位置の変更ができます。表示だけを変えてもPCキーと音高の対応は変わりません。楽器本来の音域外は無効にし、大幅な移調で音源の範囲を広げません。エレキベースなどは、表示中の一部キーだけが有効になる場合があります。

ドラムは A=キック、S=スネア、D=クローズHH、F=オープンHH、G=ロータム、H=ハイタム、J=クラッシュ、K=ライド。GM配列のMIDI入力も使えます。ドラムはキーを離しても自然な余韻を残します。

MIDIは「MIDIを接続」から使用許可を出し、入力デバイスを選びます。Note On/Off、ベロシティ、CC64ペダル、CC120/123に対応。非対応CEFや拒否された場合もPCキーは使えます。機器の接続解除時は音を止めます。ピッチベンド、アフタータッチ、MIDIファイルの自動演奏はありません。

演奏画面を開いている間は入力がJAMの画面へ向かい、移動・射撃・チャット入力を抑制します。会話、無線、チャット、別の画面を使うときはEscまたは`/jamstop`でJAMを閉じ、終わったら`/jam`で開き直してください。**画面を開いたままPTTを使えるかは未確認**です。Nによる通常PTTとVoice自体の設定は変更しません。個別の無線キーや他スクリプトのキー競合は現地確認が必要です。

同時発音は1人16音です。25音／36音のPC割り当てや画面上の多数のキーは、その数を同時に鳴らせるという意味ではありません。上限を超えると古い音から解放します。管楽器はキーを押している間持続し、120秒に達する前に安全停止します。鍵盤の同時押し数はPCキーボード本体の仕様にも依存します。

音が聞こえない場合は、次の順で確認してください。

1. 消音ボタンが「消音中」なら解除し、「聴く音量」を上げる。消音と聴く音量は端末に保存され、JAMを開き直しても残ります。
2. 自分の音だけ小さい場合は「演奏音量」を確認する。メトロノームが聞こえるかも確認する。
3. 音源準備の表示が残る場合は少し待ち、画面の案内に従って「演奏する」を押し直す。JAM全体の準備エラーなら「JAMを再読み込み」を押す。
4. 改善しない場合はEscで閉じて`/jam`で開き直す。それでも続く場合は管理者へ発生した操作と画面の文言を伝える。

「音が残る」「別画面と競合する」ときは `/jamstop`。周囲のJAM音をすぐ止めたい場合は `/jammute` を使用してください。Voiceの会話やPTTは別の機能です。

## 聴取専用で音が聞こえないとき

`/jamlisten` を開き、「消音中」ではないことと「聴く音量」を確認します。画面に「JAMの音声を有効にする」が表示された場合は、そのボタンを押してください。再開に失敗した場合はボタンが残るので、もう一度押せます。演奏者との距離が共有範囲外の場合も聞こえません。
