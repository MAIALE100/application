# 演奏のしかた

`/jam`で開き、楽器を選んで「演奏する」を押します。音源の準備が終わると演奏できます。PCキーボードのIMEはオフにしてください。鍵盤をマウスで押すこともできます。

| 操作 | キー・ボタン |
|---|---|
| 白鍵と黒鍵 | 画面のキー表示。標準はA/W/S/E/D/F/T/G/Y/H/U/J/K/O/L/P/;/′ |
| オクターブ | Zで下げる、Xで上げる。押している音は元の音程のまま離せる |
| サステイン | Spaceを押している間ON。画面ボタンは固定ON/OFF |
| 演奏終了 | Esc、終了ボタン、または`/jamstop` |
| 音だけ止める | 「すべての音を止める」 |
| 演奏音量 | 自分の楽器の音量。周囲にも反映 |
| 聴く音量 | 自分が聴くJAM全体の音量。他人には影響しない |
| 消音 | 消音ボタン、または`/jammute`。VCには影響しない |
| 設定画面だけ開く | `/jamlisten` |
| 画面を小さくする | 縮小。PCキーの演奏は継続 |

キー設定では変更対象を押して、新しいキーを押します。重複、Esc、Space、Z/X、通常PTT用のN、システムキーなどは割り当てられません。PC配列は`KeyboardEvent.code`基準です。JIS/USで記号の印字が異なる場合はキー設定で変更してください。日本語ローカル設定はPC内だけに保存されます。

ドラムは A=キック、S=スネア、D=クローズHH、F=オープンHH、G=ロータム、H=ハイタム、J=クラッシュ、K=ライド。GM配列のMIDI入力も使えます。ドラムはキーを離しても自然な余韻を残します。

MIDIは「MIDIを接続」から使用許可を出し、入力デバイスを選びます。Note On/Off、ベロシティ、CC64ペダル、CC120/123に対応。非対応CEFや拒否された場合もPCキーは使えます。機器の接続解除時は音を止めます。ピッチベンド、アフタータッチ、MIDIファイルの自動演奏はありません。

演奏中は移動・射撃・チャット入力を抑制します。チャットや別UIを使うときはEscで閉じてください。Nによる通常PTTとVoice自体の設定は変更しません。個別の無線キーや他スクリプトのキー競合は現地確認が必要です。

同時発音は1人16音です。超えると古い音から解放します。管楽器はキーを押している間持続し、120秒に達する前に安全停止します。鍵盤の同時押し数はPCキーボード本体の仕様にも依存します。

「音が残る」「別画面と競合する」ときは `/jamstop`。周囲の音をすぐ止めたい場合は `/jammute` を使用してください。
