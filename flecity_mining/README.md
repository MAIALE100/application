# Flecity Mining

Flecity向けの白市民用・完全ソロ完結型の公共鉱山金策です。

## 設計方針

- 初心者が初日から利用可能
- 採掘レベルなし
- ジョブランクなし
- 永久装備強化なし
- 企業・他プレイヤー不要
- 無料で作業開始
- NPC/システムだけで採掘から精算まで完結
- 採掘報酬と支払いはサーバー権威で処理
- Qbox qbx_core の Money API を使用

古参と初心者で「採掘速度」「容量」「レア率」に恒久差を作らず、
差をつける場合は将来の危険坑道など、本人がその都度選ぶリスク/労働量で作ります。

## v0.1.0-dev のループ

1. Davis Quartz の受付で作業開始
2. 6か所の採掘地点で原石を採掘
3. 原石を最大12個まで運搬
4. 選鉱設備で原石を鉄/銅/銀/金へ変換
5. 受付へ戻って売却
6. 続けて採掘するか /mine_end で終了

## 現在の採掘仕様

- 1回の採掘: 8.5秒
- 1回の採掘量: 1〜2個
- 原石容量: 12個
- 同一採掘地点の個人クールダウン: 30秒
- 選鉱: 10秒
- 売却: 3秒
- 支払い: cash

### 初期選鉱テーブル

| 鉱石 | 確率ウェイト | 単価 |
|---|---:|---:|
| 鉄 | 50 | $180 |
| 銅 | 30 | $240 |
| 銀 | 15 | $420 |
| 金 | 5 | $850 |

経済値はすべて config.lua に集約しています。
本番投入前にFlecityの他金策と比較して時給を調整してください。

## セキュリティ

クライアントから直接「報酬額」「採掘結果」は送信しません。

サーバー側で以下を検証します。

- Qboxプレイヤーの存在
- 作業セッション
- 開始地点
- 採掘ノードID
- プレイヤーと作業地点の距離
- 最低作業時間
- アクショントークン
- 同時作業防止
- 採掘地点クールダウン
- 原石容量
- 選鉱対象数
- 売却対象数
- Qbox AddMoney 成功結果

支払いに失敗した場合は精製鉱石を消費しません。

## 導入

resource名: flecity_mining

server.cfg:

    ensure qbx_core
    ensure flecity_mining

DBテーブルは現在不要です。

## コマンド

プレイヤー:

    /mine_status
    /mine_end

サーバーコンソール:

    mining_server_status

## 運営向け設定

運営が調整するファイルをロジック本体から分離しています。

- `config/economy.lua`: 鉱石の抽選比率・NPC買取価格・支払方法
- `config/gameplay.lua`: 採掘時間・容量・採掘量・クールダウン
- `config/locations.lua`: 受付・選鉱設備・採掘地点・ブリップ
- `OPERATIONS.md`: 運営向け設定ガイド

報酬調整のために client/server のロジックを編集する必要はありません。

確認コマンド:

    mining_selftest
    mining_healthcheck
    mining_economy

## 今後の候補

通常鉱山の動作と経済バランスを確定した後に、別ルートとして追加します。

- 重労働区画
  - 作業工程が長い
  - 安定して通常より高収益
- 危険坑道
  - ガス、崩落、視界、持ち帰り失敗など
  - 高期待値
- 希少鉱脈
  - レベル不要
  - 誰でも同一条件
  - 一発報酬

これらにも恒久レベル補正は入れません。
