# Flecity Mining - TESTING

## 起動確認

1. ensure qbx_core
2. ensure flecity_mining
3. サーバーコンソールでエラーがないこと
4. マップに「公共鉱山」ブリップが出ること

## 正常系

### 1. 受付

- 受付へ行く
- [E] 鉱山作業を開始
- 開始通知が出る
- /mine_status で 原石 0/12

### 2. 採掘

- 採掘地点でE
- 約8.5秒固定される
- 完了後、原石が1〜2増える
- 同じ地点を直後に再使用するとクールダウン通知
- 別地点では採掘可能

### 3. 満載

- 原石12個まで採掘
- 12個を超えない
- 満載時は追加採掘できない

### 4. 選鉱

- 選鉱設備へ移動
- Eで約10秒
- 原石が0になる
- 鉄/銅/銀/金へ変換される
- /mine_status で内訳確認

### 5. 売却

- 受付へ戻る
- Eで約3秒
- cashが増える
- 精製鉱石が0になる
- 同じ鉱石を二重売却できない

## 異常系 / 悪用確認

- 受付から離れてstartイベントを送っても開始しない
- 採掘地点から離れてbeginMineを送っても開始しない
- 存在しないnodeIdを送っても採掘できない
- 作業完了前にfinishActionを送っても報酬が出ない
- 他のtokenでfinishActionしても報酬が出ない
- 採掘中に死亡するとキャンセルされる
- 採掘中にresourceをrestartしてもプレイヤーがFreezeされたままにならない
- qbx_core停止時に現金が増えない
- 支払い失敗時に精製鉱石が消えない
- 連打しても同時に複数アクションが開始しない

## 現地確認が必要な項目

座標はDavis Quartz標準マップを前提にしています。

- 受付マーカーが地面に埋まっていないか
- 6採掘地点が岩/壁の近くに自然に見えるか
- 選鉱設備マーカーが実景と合っているか
- WORLD_HUMAN_HAMMERING が地形に対して不自然でないか
- WORLD_HUMAN_WELDING が設備に対して不自然でないか

座標・演出は現地スクリーンショットを見ながら調整します。

## 経済テスト

最低3セット計測:

- 1ロード(原石12個)の所要時間
- 1ロードの売上
- 30分換算時給

初期値は仮設定です。
本番の金策順位に合わせて config.lua の単価/時間だけ調整します。
