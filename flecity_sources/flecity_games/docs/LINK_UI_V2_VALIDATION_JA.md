## 現行機能の一覧

### 入口・ルーム・設定

- 作成は `partyCreateRoom {}`、参加は `partyJoinRoom {code}`。数字コードは設定値3〜6桁、既定4桁。画像の6桁へ固定しない。
- 重複作成・再参加時の既存ルーム復帰、コード検証、不存在・満員・進行中の拒否、退出の二度押し確認を維持する。
- 接続/切断、アプリ開閉、Ready、ホスト、AIの区別を表示する。
- ルーム全体は最大10人。実際の新規参加上限は選択中ゲームの上限との小さい方。切断枠の回収・ホスト移行はサーバーに任せる。
- ゲーム・設定変更はロビーのホストのみ。変更時はサーバーが人間のReadyを解除する。ゲストは設定を閲覧できる。
- 開始はホストのみ。ゲームの人数範囲内、全接続メンバーがアプリを開き、全員Readyのとき開始可能。
- サウンド・動きを抑える設定の保存先、既定値、適用を維持する。他アプリが保存した省略項目を消さない。
- LINK+の加入、期限、自動更新、停止・再開、明示的な二度押し購入確認を設定内に維持する。トップの常時勧誘枠は設けない。
- 会員状態はサーバーから再取得する。画面復元スナップショットを契約判定の正本として扱わない。

### 結果・復帰・大画面

- 勝敗、順位、同点、未回答、タイムアウト、人数不足/退出による中断、秘密の公開とゲーム別結果を維持する。
- ホストのロビー復帰、結果の最低表示時間、テトリス再戦（ソロAI/対人で異なる導線）、次ラウンドのReadyを維持する。
- お絵かき伝言の前/次/全表示、過去の文章と絵の順序を維持する。
- push更新、revisionによる古い状態の拒否、10秒間隔の補助取得、切断後の同一メンバー復帰、アプリ一時停止/再開を維持する。
- スマホ/大画面は一つの操作権を共有する。通信・描画中・成り確認中の切替禁止、メモリー上の入力・下書き・盤面復元、診断を維持する。
- スナップショットに含む秘密お題、入力、線、盤面を永続保存・ログ出力しない。受領が不明なゲーム/決済変更を自動再送しない。

### 今回の画面切替互換性調整

- 新設したhome/join/createの表示先と、既に取得した表示名だけを、既存のメモリー上の画面スナップショットに追加する。大画面へ切り替えたときにも同じ画面へ戻すためであり、サーバーゲーム状態・保存スキーマ・NUI actionは変えない。
- 大画面から復元するとき、現在の伝言token/stepから既存の `telephoneActiveStep` を復元し、転送した未送信の絵が初期化されることを防ぐ。手番が変化した場合は従来どおりサーバー状態に従う。
- LINKの設定/プロフィールダイアログが開いているとき、Escapeはそのダイアログを閉じる。ダイアログがない場合の大画面からスマホへ戻る既存操作は維持する。
- 伝言の大画面canvasの表示高さを調整し、送信操作が画面の外へ押し出されにくくする。canvasの画素数・縦横比・送信される線と座標は維持する。

## 機能保護のため保留する参考仕様

現行サーバーには以下の機能とAPIがない。UI刷新だけで追加すると、通信・データ構造・認証や権限を変更するため保留する。動作しない安全機能や架空データで代用しない。

| 参考仕様 | 現行との対応 |
| --- | --- |
| 共有ルーム名 | サーバーのルーム名項目・更新APIなし。ホスト名/ルームコードから表示可能な範囲に限定 |
| パスワード認証・生成・コピー | パスワード保存/照合APIなし。保護されているように見せない |
| 公開ルーム一覧・検索・更新 | 公開一覧APIなし。コードによる既存参加を維持 |
| 招待・キックなど参加者管理 | 新しい管理操作・権限を追加しない |
| 観戦・ハンデ・持ち時間変更 | 現行の設定/APIなし。画像のサンプル値を固定実装しない |
| 名前/アバターの編集 | LINKのプロフィール編集APIなし。ルーム参加時の実名と会員状態を使用できる範囲に限定 |
| 管理者画面 | 現行のLINK管理者ページなし。サーバー診断コマンドを新しい一般UIへ公開しない |

別資料として指定された `LINK — UI Redesign Implementation Instructions (v2.0)` の独立本文と、指定場所の `message.txt` は取得できていない。受領済みの統合指示書・4画像・現行コードから確定する範囲を実装する。

## 最終オフライン検証と配布判定

- 新規ブラウザ試験は18/18 PASS、0 FAIL、0 skip。別途3件の配置計測もPASS。全15ゲームの選択/表示、既存の盤面入力、権限/Ready/会員制限、設定、コピー、320/390px、画面切替とルート復元を検査した。試験中の4 UIソースのSHA256は不変。
- 既存Node試験は20件中19 PASS / 1 FAIL（基準版は18 PASS / 2 FAIL）。残るFAILは古い描画単体試験の関数抽出とローカル48点制限の仮定。既存ファイルは変更せず、現在の実関数でローカル線の保持・送信プレビュー48点/最終128点・両端維持を追加検査してPASSとした。
- 伝言の大画面切替では、復元した手番キーが未設定のため、ローカル描画がサーバー下書きで消える基準版の不具合を修正した。既存のメモリー上のUI復元処理に限定し、サーバー通信・保存形式・ゲームルールは変更していない。既存の伝言/テトリス/LOOPを含む画面切替試験はPASS。
- 新UIの設定ダイアログをEscapeで閉じてから通常の大画面切替を行う。参加/作成画面の表示位置と既知の名前も、既存の非永続スナップショット内だけで引き継ぐ。
- 最終静的検査は凍結62/62一致、元181 IDすべて保持/重複0、41 callback名維持、JS8＋起動script1の構文PASS。Lua16ファイルの構文もPASS。
