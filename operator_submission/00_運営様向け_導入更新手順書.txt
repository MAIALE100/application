==================================================
■ 最短の導入手順
==================================================

【1】PuriPhotoを更新してください

既存の puriphoto リソースを、
PuriPhoto_v1.1.1_Update_Flecity_Operator.zip 内の
puriphoto フォルダで差し替えてください。

既存アルバム等はDB側に保存されており、
本更新に既存データを削除する処理は含めておりません。
不足テーブル・不足列は起動時に自動作成・自動更新されます。

念のため、既存 puriphoto フォルダのバックアップのみ
事前に取得いただけますとより安全です。


【2】FLEPURI本体を配置してください

FLEPURI_v1.0.4_Flecity_Operator.zip 内の
puribooth フォルダを resources 配下へ配置してください。

配置例:
resources/[lb-phone]/puribooth/


【3】server.cfgへFLEPURIを追加してください

既にPuriPhotoの ensure がある場合は、その後ろに

ensure puribooth

を1行追加いただくだけで問題ございません。

起動順の目安:
ensure qbx_core
ensure oxmysql
ensure lb-phone
ensure screenshot-basic
ensure puriphoto
ensure puribooth


==================================================
■ 運営様権限でお願いしたい設定
==================================================

FLEPURIの管理権限および売上入金先は、
既定で「weazel」を使用する設定にしております。

恐れ入りますが、以下2点のみ運営様側でご確認をお願いいたします。


【A】QBoxのweazel job

・weazel job がサーバーへ永続登録されていること
・FLEPURIの設置・撤去・料金変更・売上管理を行う方に
  weazel job が付与されていること

FLEPURI本番版からjobを勝手に新規作成することはございません。
サーバー既存のjob管理方式を尊重する仕様です。


【B】Renewed-Bankingのweazel会社口座

FLEPURIの売上は、
Renewed-Bankingの会社口座「weazel」へ回収する設定です。

設定値:
Config.Payout.account = "weazel"

恐れ入りますが、運営様の通常の管理手順にて、

・会社口座名 / account ID が weazel
・weazel job と会社口座が適切に紐づいている
・Renewed-Bankingから当該口座を参照・入金できる

状態であることをご確認ください。

もしFlecity様の本番環境で、
Weazelの会社口座IDが「weazel」以外となっている場合は、
こちらでFLEPURI側を合わせて修正いたしますので、
口座IDだけお知らせいただければ運営様側でLuaを編集いただく必要はございません。


==================================================
■ 反映時のコマンド
==================================================

サーバー全体の再起動は原則不要です。

txAdmin / サーバーコンソールで、以下の順にお願いいたします。

refresh
restart puriphoto
ensure puribooth
puribooth_selftest

PuriPhoto再起動時に依存関係の都合でpuriboothが停止した場合も、
最後に「ensure puribooth」としていただければ問題ございません。


==================================================
■ selftestで確認していただきたい表示
==================================================

最終的に、

[puribooth] selftest PASS

となれば導入完了です。

主な確認項目:
・qbx_core = PASS
・oxmysql = PASS
・lb-phone = PASS
・screenshot-basic = PASS
・puriphoto = PASS
・puriphoto_ui = PASS
・management_job = PASS
・payout = PASS
・database = PASS
・accounting = PASS
・refunds = PASS(0)
・collections = PASS(0)

もし
management_job=FAIL(weazel)
となる場合:
→ weazel jobの永続登録をご確認ください。

もし
payout=FAIL(...)
となる場合:
→ Renewed-Bankingのweazel会社口座をご確認ください。

その他のエラーにつきましては、
運営様側でコードやDBを修正いただく必要はございません。
表示されたログをご共有いただけましたら、こちらで確認・修正いたします。

今回の更新版には主に以下を含みます。

==================================================
■ FLEPURIの管理コマンド
==================================================

weazel jobの方のみ使用できます。

/puribooth place
  フレプリ台を新規設置します。

/puribooth remove
  近くのフレプリ台を撤去します。
  未回収売上がある台は安全のため撤去できません。

/puribooth price <料金> [台ID]
  台ごとの料金を変更します。

/puribooth sales
  全台の料金・未回収売上・累計売上・撮影回数を確認します。

/puribooth collect all
/puribooth collect <台ID>
  未回収売上をRenewed-Bankingのweazel会社口座へ回収します。

/puribooth list
  設置済み台数を確認します。

■ フォントについて
==================================================

フォント本体はライセンス・配布元管理を尊重し、
FLEPURIのZIPには同梱しておりません。

ただし、フォント未導入でもフォールバック書体で動作するため、
初回導入時の必須作業ではございません。

意図したプリクラ風書体をご利用いただく場合のみ、
以下の公式配布元から取得して
puribooth/ui/fonts/ へ配置いただけます。

■ 不具合・保守について
==================================================

導入後に不具合がございましたら、
運営様側でLua・NUI・DBの修正を行っていただく必要はございません。

可能であれば、
・発生日時
・該当プレイヤーのCSN / citizenid
・該当フレプリ台ID（分かる場合のみ）
・行った操作
・画面表示またはコンソールログ

をご共有いただければ、こちらで原因確認・修正版作成まで対応いたします。
