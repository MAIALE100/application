# 最終監査メモ

- Diary更新/削除: `owner_identifier` をSQL条件に含め、他キャラのID直接指定を拒否。
- 共有: Diary所有権、電話番号存在、自分自身、重複、共有枠上限をサーバー側で検証。
- Shared削除: ログイン中キャラクターの電話番号と一致する共有のみ削除。
- 共有枠購入: 商品ID・現在枠・+5段階・50人上限・価格をサーバー側で再検証。
- 二重購入対策: 決済直前にEntitlementを再取得し、古い状態からの購入要求を拒否。
- 決済Adapter: 引落とWeazel入金を一体の処理として成功/失敗させるインターフェースへ固定。片側だけ成功する実装は禁止。
- キャラクターID: 取得失敗時にlicenseへフォールバックせずfail-closed。
- SQL: ユーザー入力をプレースホルダで渡す。
- 写真: 最大5枚、URL長制限、http/httpsのみ保存。
- 本文/タイトル: サーバー側でも長さ制限。
- 連打: 保存・共有・購入にサーバー側クールダウン。
- 開発用コマンド/旧RC移行コマンド: PAYMENT-PENDINGから除去。

課金Adapterは未接続のため、実決済に関する最終監査はAdapter接続後に実施します。
