# PuriBooth Changelog

## 0.7.1 - 2026-10-26

### 肌なめらか調整
- GTA人物で変化が見えにくかった肌なめらか補正を強化
- 肌色判定範囲を広げ、顔・首・腕・脚を拾いやすく調整
- 最大時の平滑化強度とぼかし半径を引き上げ
- 輪郭付近はエッジ保護を残しつつ、肌内部はよりしっかり滑らかに補正

## 0.7.0 - 2026-10-26

### 肌補正
- 肌色部分だけに効く「肌なめらか」スライダーを追加
- 肌の平滑化は輪郭・髪・背景を極力崩さないエッジ保護つき
- 白肌感・血色感と組み合わせてプリクラらしい人物補正を強化
- ナチュラル / プリクラ / Y2K / モノクロ / ふわ盛り / クール / 夜補正に肌なめらか値を追加
- 新しい撮影セッション開始時に肌補正値も確実に初期化
- 「押して補正前を確認」を追加し、設定を変えずに元画像と比較可能

## 0.6.4 - 2026-10-26

### 盛りプリセット調整
- クールが実際に寒色方向へ変化するよう、あたたかさをマイナス方向にも対応
- 夜補正の白飛びを抑制
- プリクラ / Y2K / ふわ盛り / モノクロの強度差を整理
- 各プリセットの見た目をより判別しやすく調整

## 0.6.3 - 2026-10-26

### 盛り調整
- ふわ盛りプリセットのボケと発光を弱め、輪郭を残す方向へ調整
- プリセット適用時のステータス表示をボタン表記に合わせて日本語化
- ナチュラル / プリクラ / ふわ盛り等の表示を統一

## 0.6.2 - 2026-10-26

### 肌補正
- 白肌感を写真全体ではなく肌色領域中心に適用
- 血色感を写真全体ではなく肌色領域中心に適用
- 背景テーマの色が白肌感・血色感で崩れにくいよう改善
- 盛り画面に肌補正の説明を追加

## 0.6.1 - 2026-10-26

### 盛り調整
- 発光感の最大効果を大幅に強化
- 白肌感の最大効果を強化
- 血色感の最大効果を強化
- ナチュラルでは追加盛りを0にし、比較しやすく調整
- プリクラ / Y2K / ふわ盛り / クール / 夜補正の各プリセットを再調整

## 0.6.0 - 2026-10-26

### 盛り強化
- 発光感スライダーを追加
- 白肌感スライダーを追加
- 血色感スライダーを追加
- 既存プリセットへ新しい盛りパラメータを統合
- ふわ盛り / クール / 夜補正でも盛り効果を連動

### 安定性
- 発光処理をオフスクリーンCanvas経由に変更してNUI描画を安定化
- 次の利用者へ前回のレイアウト・盛り・写真位置が残らないよう編集状態をセッションごとに初期化

## 0.5.0 - 2026-10-26

- 各写真ごとに100〜240%の拡大調整を追加
- 各写真ごとに左右・上下のトリミング位置調整を追加
- 1枚だけリセット / 4枚すべてリセットを追加
- 4コマ・4列・メイン＋3枚・1枚大きくの全レイアウトへ位置調整を反映

### 盛り
- 「ふわ盛り」プリセットを追加
- 「クール」プリセットを追加
- 夜間撮影用の「夜補正」プリセットを追加
