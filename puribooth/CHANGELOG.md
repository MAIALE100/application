# PuriBooth Changelog

## 0.4.0 - 2026-10-26

### 撮影
- カメラを目線付近へ調整
- 2〜4枚目をPOSE READY待機式へ変更
- 各写真の前に利用者が任意でカウントダウン開始可能
- 撮影中Backspaceキャンセル対応
- キャンセル時のカウントダウン残留を修正
- 撮影タイムアウトを10分へ延長
- 技術失敗 / タイムアウト時の返金強化

### 背景・床
- 一時背景・床テーマを追加
- PINK / WHITE / Y2K / BLACK / HEARTS / MINT / LAVENDER / SKY / なし
- カスタム画像URL対応
- 背景16:9 / 床2:1で個別ラスタライズ
- runtime textureを撮影ごとに新規生成しPINK固定問題を修正
- カメラ確認 / 撮影中だけスタジオ面を表示
- 背景・床・URLはDBへ保存しない
- Rキーで撮影開始前に背景・床を選び直し可能

### 照明
- 撮影中の補助ライトを追加
- 夜間の人物黒潰れを軽減

### 編集
- スタンプ追加
- Undo / Redo
- スタンプ・文字の選択
- ドラッグ移動
- 拡大 / 縮小
- 左右回転
- 個別削除
- 選択ガイドを完成画像へ焼き込まないよう修正

### 管理
- 半透明配置プレビュー
- 移動 / 回転 / 高さ調整
- 配置時の撮影範囲表示
- 配置時カメラプレビュー
- DB永続化
- 管理者登録
- 管理コマンド早見表を追加

### PuriPhoto連携
- booth import通知payloadをUI listenerと統一
- 動的なブース名・位置名を引き継ぐよう修正
- PuriPhoto停止中は課金を開始しない
- 編集中にPuriPhotoが停止してもPuriBooth編集画面を保持
- puriphotoを依存リソースとして明示

### 開発・導入
- 重複PuriPhotoをresources外へ自動退避
- npm lockずれを自動修復するデプロイ処理
- 管理コマンド表をD:\FiveM_Devへ自動コピー
- README / selftestを拡充
