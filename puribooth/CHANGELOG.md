# PuriBooth Changelog

## 0.4.2 - 2026-10-26

### 日本語表示修正
- GTAネイティブ文字描画で日本語が□になる問題を修正
- 撮影手順、ガイド説明、ポーズ待機、カウントダウンをNUI HUD描画へ移行
- 撮影ロジック・背景・カメラ・エモート制御は変更せず表示方式だけを差し替え
- NUI HUDは撮影時に残留しない短時間更新方式

## 0.4.1 - 2026-10-26

### 撮影ガイド
- 実カメラFOVから写る横幅を算出
- 白枠で写る目安を表示
- 緑枠で人物が切れにくい安全範囲を表示
- 最大4人用の立ち位置マーカーを表示
- 同じプリクラ台の近くにいる参加者全員へガイドを表示
- Gキーでガイド表示 / 非表示
- 実撮影開始時は自動でガイドを非表示

### 日本語化
- 撮影待機 / カメラ確認 / カウントダウン / ポーズ待機を日本語化
- 配置プレビューの画面案内を日本語化
- 背景・床選択のプリセット名と状態表示を日本語化
- 編集画面の英語ラベルを日本語化
- 新規設置するプリクラ台の表示名を日本語化

## 0.4.0 - 2026-10-26

### 撮影
- カメラを目線付近へ調整
- 2〜4枚目をPOSE READY待機式へ変更
- 各写真の前に利用者が任意でカウントダウン開始可能
- 撮影中Backspaceキャンセル対応
- キャンセル時のカウントダウン残留を修正
- 撮影タイムアウトを10分へ延長
- 技術失敗 / タイムアウト時の返金強化

### 背景・床
- 一時背景・床テーマを追加
- PINK / WHITE / Y2K / BLACK / HEARTS / MINT / LAVENDER / SKY / なし
- カスタム画像URL対応
- 背景16:9 / 床2:1で個別ラスタライズ
- runtime textureを撮影ごとに新規生成しPINK固定問題を修正
- カメラ確認 / 撮影中だけスタジオ面を表示
- 背景・床・URLはDBへ保存しない
- Rキーで撮影開始前に背景・床を選び直し可能

### 照明
- 撮影中の補助ライトを追加
- 夜間の人物黒潰れを軽減

### 編集
- スタンプ追加
- Undo / Redo
- スタンプ・文字の選択
- ドラッグ移動
- 拡大 / 縮小
- 左右回転
- 個別削除
- 選択ガイドを完成画像へ焼き込まないよう修正

### 管理
- 半透明配置プレビュー
- 移動 / 回転 / 高さ調整
- 配置時の撮影範囲表示
- 配置時カメラプレビュー
- DB永続化
- 管理者登録
- 管理コマンド早見表を追加

### PuriPhoto連携
- booth import通知payloadをUI listenerと統一
- 動的なブース名・位置名を引き継ぐよう修正
