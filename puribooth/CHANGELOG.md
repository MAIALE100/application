# PuriBooth Changelog

## 0.8.9 - 2026-10-26

### 自動生成停止
- 旧リージョン用のレガシーフレプリ台自動生成を無効化
- アップデート / resource restart / server restart 後に、DBが空でも勝手にフレプリ台を作成しない
- 今後の設置は /puribooth place の管理者配置だけで管理

## 0.8.8 - 2026-10-26

### 設置操作の微調整
- 通常移動速度を 0.035 → 0.012 に低速化
- Q/E回転を 1.0° → 0.5° 刻みに変更
- PageUp/PageDown高さ調整を 0.02 → 0.008 に低速化
- SHIFT高速移動は維持し、粗移動と微調整を両立

## 0.8.7 - 2026-10-26

### 撮影方向反転
- 撮影範囲を筐体の反対側から正面側へ反転
- 撮影カメラ位置 / 注視点を同じ側へ反転
- 背景・床サーフェスも正面側へ移動
- 撮影用ライトの前後オフセットも反転
- 設置プレビューの水色撮影方向矢印は新しい正面側へ自動追従

## 0.8.6 - 2026-10-26

### 設置HUD修正
- 設置プレビューの2行説明が同じHUD枠を奪い合ってちらつく問題を修正
- 撮影範囲 / 撮影方向説明と操作キー説明を別スロットへ固定
- drawText2d に明示的なHUDスロット指定を追加

## 0.8.5 - 2026-10-26

### インタラクト表示へ簡素化
- 仮の板・ネオン・リングライト等の外装シェルを撤去
- 既存筐体の足元へ常時見える水色インタラクト円を追加
- 空き台は水色、近距離では明るい水色、使用中はピンクで表示
- インタラクト円を緩やかにパルスさせ、触れる台だと分かりやすく改善
- 近距離では FLEPURI と料金 / 使用中ステータスを表示

### 設置プレビュー
- 筐体から撮影範囲へ伸びる水色の撮影方向矢印を追加
- 矢印の先端・ドット・SHOOT AREA表示を追加
- 従来のピンク撮影範囲枠と白いカメラ視線を維持
- Q/E回転時に撮影方向と撮影範囲が一緒に回るため、設置前に向きを確認可能

## 0.8.4 - 2026-10-26

### 複数台同時利用
- セッション・背景・床・カウントダウンを boothId 単位で分離
- 支払った本人は常に自分のフレプリ台を優先
- 同行者は撮影エリア内で最寄りの使用中フレプリ台だけに紐付く
- 隣の台のカウントダウンが割り込まないよう配信先を限定
- 複数台の撮影ガイドが同時表示されないよう最寄り1台だけ描画

### 背景・床共有
- 支払った人が選んだ背景・床を同じ撮影エリアの同行者へ一時同期
- カスタム画像は latent event で転送し大容量同期の瞬間的な負荷を軽減
- 撮影エリアへ後から入った同行者にも自動同期
- 撮影エリアを離れた人から背景・床を自動破棄
- セッション終了時に同期テーマを全参加者から破棄
- 古い遅延テーマが次セッションへ残らないバージョンガードを追加
- 撮影用ライトも紐付いた1台だけ表示

## 0.8.3 - 2026-10-26

- FLEPURI看板とリングライトも同じ正面位置へ追従
- 左右シェルを筐体全奥行きから前端の細い袖へ縮小
- ネオン縁を正面カバー位置へ移動
