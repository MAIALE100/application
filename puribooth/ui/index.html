FLEPURI

フレプリ

4枚撮影
レイアウト・盛り・フレームを選んで編集

レイアウト

4枚をどう組み合わせるか選びます。

写真調整

各写真の拡大と位置を個別に調整できます。

1枚目：拡大 100% / 左右 0 / 上下 0

盛り

プリクラらしい明るさ・色味・やわらかさを調整します。肌なめらか・白肌感・血色感は肌色部分を中心に反映します。

顔盛り

写真を選び、顔1〜6を選んでから写真内の顔をクリック。友達ごとに目・小顔・明るさ・血色を個別調整できます。

1枚目 / 顔1：未登録。写真内の顔をクリックしてください。

フレーム

スタンプ

スタンプを選んで、写真の好きな場所をクリック。

文字

プリクラ文字を作って、写真の好きな場所に配置できます。

文字スタイル

フォント

配置済みの文字を選んでから押すと、その文字だけフォントを変更できます。

色

配置後もドラッグ・回転・拡大縮小・削除できます。

落書き

写真の上を直接ドラッグして描けます。

消しゴムはなぞった部分だけ消します。写真や文字・スタンプは消えません。
