# PuriPhoto 公募スタンプ追加ガイド

PuriPhoto の既存基本スタンプは残したまま、採用された公募作品を追加していく運用を想定しています。

## 推奨データ
- 透過 PNG または透過 WebP
- 正方形キャンバス推奨
- 推奨サイズ: 512x512
- 最大目安: 1024x1024
- 余白を取りすぎず、被写体が中央付近に収まること
- ファイル名は半角英数字とハイフン推奨

## 採用時の保存先
`ui/public/stamps/community/`

例:
`ui/public/stamps/community/sakura-01.webp`

## カタログ登録例
`App.tsx` の `COMMUNITY_STAMPS` に追加します。

```ts
{ id: 'community-sakura-01', label: 'さくら', category: 'community', image: 'community/sakura-01.webp', author: '作者名' }
```

`id` は重複禁止です。

## 公募時に確認したい条件
- 投稿者本人が制作した作品、または利用許諾を持つ作品であること
- 第三者のキャラクター、企業ロゴ、商標、写真素材などを無断使用しないこと
- PuriPhoto / Flecity 内でスタンプとして使用・配布されることに投稿者が同意していること
- 成人向け、差別的、攻撃的、違法性のある内容を含まないこと
- 採用後にゲーム内表示へ合わせた縮小、圧縮、余白調整などを行う場合があること

## 表示
公募スタンプが1件以上登録されると、スタンプカテゴリに「みんなの」が自動表示されます。
作者名が設定されている場合は、スタンプ一覧に `by 作者名` と表示されます。
