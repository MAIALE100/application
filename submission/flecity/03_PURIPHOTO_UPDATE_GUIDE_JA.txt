PuriPhoto v1.1.1
Flecity運営様向け 更新手順

平素より大変お世話になっております。

こちらは、以前ご提出したPuriPhotoへ機能追加・FLEPURI連携を行った
更新版リソースとなります。

主な追加・改善内容:
・アルバム関連機能の拡張
・写真ごとのメモ対応
・マイスポット登録
・おすすめ撮影スポット
・FLEPURIから完成画像を直接受け取る連携
・FLEPURI受け渡し時のreceipt確認
・既存DBへの自動schema追加／移行

────────────────────────
■ 更新方法
────────────────────────

1. 念のため既存 puriphoto フォルダをバックアップしてください。

2. 稼働中の場合:
   stop puriphoto

3. 既存 puriphoto フォルダを、
   本ZIP内の puriphoto フォルダへ「フォルダ単位で差し替え」てください。

   古いui/distファイルを残さないため、
   上書きコピーより差し替えを推奨しております。

4. 下記を実行してください。

   refresh
   ensure puriphoto

5. コンソールに

   [puriphoto] selftest PASS

   が表示されれば更新完了です。

────────────────────────
■ 運営様側で不要な作業
────────────────────────

・SQLの手動実行
・npm install / npm build
・UIの手動ビルド
・既存アルバムデータの移行作業

上記は不要です。

production UIはビルド済みのものを同梱しております。
DBは不足table / columnを自動作成・自動移行します。

FLEPURIも同時導入される場合は、
puriphoto → puribooth の順で起動をお願いいたします。

何卒よろしくお願い申し上げます。
