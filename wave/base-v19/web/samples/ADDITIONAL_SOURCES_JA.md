# 追加録音楽器の由来とライセンス

この候補はグランドピアノ統合版とは別の開発候補。各元アーカイブは開発領域の `original`、抽出原音は `selected-original` に保存した。WAVE用には選択したFLACをOgg Vorbisへ変換したものだけを含む。

| WAVE楽器 | 原音源・作者 | 公式ページ | ライセンス | 加工 |
|---|---|---|---|---|
| 録音アコースティックギター | FreePats Spanish Classical Guitar、roberto@zenvoid.org | https://freepats.zenvoid.org/Guitar/acoustic-guitar.html | CC0 1.0 | 10音高を選択し最大6秒のOggへ変換 |
| 録音エレキベース | FreePats Bass Guitar YR / Picked、Andrea Biasior | https://freepats.zenvoid.org/ElectricGuitar/clean-electric-bass.html | CC0 1.0 | 5音高を選択し最大5秒のOggへ変換 |
| 録音ドラムセット | MuldjordKit、Lars Muldjord録音、FreePats版はroberto@zenvoid.orgが編成 | https://freepats.zenvoid.org/Percussion/acoustic-drum-kit.html | CC BY 4.0 | キック、スネア、ハイハット、タム、クラッシュ、ライドを選択し最大3～6秒のOggへ変換 |
| ドラムのクラップ | FreePats World Percussion、roberto@zenvoid.orgほか | https://freepats.zenvoid.org/Percussion/world-and-rare-percussion.html | CC0 1.0 | 1音を選択し最大3秒のOggへ変換 |

MuldjordKitのCC BY 4.0表記は https://creativecommons.org/licenses/by/4.0/ に従う。元の演奏・録音に対するクレジットを上記のとおり維持し、WAVE向けの短縮・圧縮を明記する。原音源・ライセンス本文は開発領域の抽出フォルダに保存する。
