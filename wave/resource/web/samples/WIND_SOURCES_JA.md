# WAVE 追加楽器音源の出典

- **クラリネット**：FreePats Clarinet, Tyler Dence / Kaili Dence, CC0 1.0, https://freepats.zenvoid.org/Reed/clarinet.html
- **トロンボーン**：Versilian Studios, VSCO 2 Community Edition, OldTrombone Sustain, CC0 1.0, https://github.com/sgossner/VSCO-2-CE

録音サンプルはアプリの音色として使用する。元データは配布元の権利表示を参照。`map.json`に各加工済みファイルのSHA256を記録。ダウンロードや変換に失敗した場合は更新パッケージを作らない。
